# DEW — Jewelry Atelier

Экспериментальный тёмный премиальный магазин изделий из бисера и натуральных камней.

## Стек
- Next.js 16 / React 19
- TypeScript
- CSS без UI-фреймворков

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Страницы
- `/` — необычная главная с выбором настроения камня
- `/catalog` — поиск и фильтр товаров по категориям
- `/product/noir-orbit` — карточка изделия, выбор размера и количества
- `/cart` — шкатулка/корзина с подсчётом стоимости
- `/checkout` — демонстрационная форма оформления

Демо-данные — в `lib/products.ts`. Все изделия и цены условные. Изображения товаров представлены CSS-иллюстрациями, пока не загружены настоящие фото.

Корзина сохраняется в `localStorage` браузера. Никакой оплаты, резервирования наличия или отправки заказа сейчас нет. Форма оформления проверяет обязательные поля, но **не отправляет и не сохраняет персональные данные на сервере**.

## Админка — следующий этап

Нужны отдельная БД, защищённая серверная авторизация через email (например, проверенные magic links или OAuth), allowlist администраторов/роли **на сервере**, операции с товарами и заказами, управление остатками и фото. Администраторские email-адреса и ключи нельзя хранить в публичном коде. До реализации контроля доступа маршрута `/admin` нет.
