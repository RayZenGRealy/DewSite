# DEW — Jewelry Atelier

Премиальный интернет-магазин авторских украшений из натуральных камней и бисера.

## Стек

- Next.js 16
- React 19
- TypeScript
- Custom CSS

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Первый этап

- необычный dark-luxury hero
- интерактивный выбор камня / настроения
- асимметричная витрина коллекции
- избранное на клиенте
- адаптивная мобильная версия
- заготовка секции истории мастерской

Следующие этапы: реальные товары и фото, карточка товара, корзина, checkout, база данных и админ-панель.
